# Hindi Video Dubber — starter

This is a mobile-friendly front-end starter. It lets you select a video, preview it, choose source/target languages and download a JSON file containing the project settings.

## Run it
1. Extract this ZIP on your phone or computer.
2. Open `index.html` in a modern browser.
3. Choose a video and select the language settings.
4. Tap **Prepare project file** to download `dubbing-project.json`.

## Important limitation
This starter is **not yet an automatic AI dubbing system**. It does not transcribe speech, translate dialogue, create AI voices, synchronize dubbed speech, separate background music, or export a finished video. Those features require a backend processing pipeline and suitable speech/translation/audio models. The starter deliberately does not claim otherwise and does not upload your video.

## GitHub Pages
Upload the extracted files (`index.html`, `styles.css`, `app.js`, and `README.md`) into the root of your GitHub repository, then enable GitHub Pages in the repository's Settings → Pages. Do not upload only the ZIP if you want GitHub Pages to show the website.
